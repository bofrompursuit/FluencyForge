What you'll build

Three agents, shipped by Friday

Every day ends with something that runs. No slideware, no “here's what you could do” — you build, you test, you keep it.

Agent 01 · saves ~3 hrs/wk

The repetitive-task killer

Take the one task you do every week that never changes shape, and hand it off. You'll define the input, the output format, and the guardrails — then watch it run without you.

Example Turn each week's raw campaign metrics into the same formatted Slack recap your team already expects.
Agent 02 · saves ~5 hrs/wk

The multi-step workflow

Chain steps together so one agent researches, analyses, drafts and self-reviews before it ever reaches you. This is where most people's mental model finally clicks.

Example Research three competitors, pull the positioning differences, draft a one-page brief, then critique its own draft.
Agent 03 · your call

Your own bottleneck

The capstone. You pick the thing that actually slows your week down, and both coaches work it with you live. This is the one you'll demo on Friday.

Example Whatever made you open this page. Past cohorts: RFP triage, QBR decks, inbound lead scoring, podcast repurposing.

Is this for you?

Built for people who don't write code

IN //fluency is deliberately narrow. If you're a marketer, operator, founder or analyst drowning in repeatable work, this is aimed squarely at you. If you're looking for a framework deep-dive or model fine-tuning, it isn't.

Seats are capped at 50 so both coaches can review every agent personally. When a cohort fills, the next one opens the following Monday.

This is a fit if…

  • ✓ You spend 5+ hours a week on work that follows the same shape every time
  • ✓ You've used ChatGPT or Claude but never got past one-off prompts
  • ✓ You can commit 60 focused minutes a day for one week
  • ✓ You have one real task you'd hand off tomorrow if you could
  • ✓ You want something running by Friday, not a certificate
